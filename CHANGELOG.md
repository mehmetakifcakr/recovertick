# Changelog

## 0.1.0 — Initial source release

* Typed pure reducer with state/event/fault/effect associated types.
* Nondecreasing logical ticks and positive fixed backoff.
* Bounded retries, overflow handling and terminal fallback.
* Allocation-free segmented journal with atomic full-buffer rejection.
* Semantic trace replay and an executor-independent async input adapter.
* Regression tests, runnable simulation, footprint report and host benchmark.
* CI matrix and tag-driven crate/GitHub release workflow.
